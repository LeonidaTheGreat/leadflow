## Deployment Notes

- Cron job runs daily at 10:00 UTC via Vercel Cron
- Endpoint: `POST /api/cron/send-trial-emails`
- Requires `CRON_SECRET` environment variable for authorization
- Uses Resend API for email delivery
- All emails logged to `trial_email_logs` table
