**Detail:** UC chain completion 0% across 6+ active UCs

### Root Cause

The heartbeat executor's `chain_completion_rate` calculation was performing **case-sensitive** comparison between:
- **Workflow steps** from the `use_cases` table: `['Product', 'Dev', 'QC']` (mixed case)
- **Task agent_ids** from the `tasks` table: `['product', 'dev', 'qc']` (lowercase)

**The Bug:**
```javascript
// Before (case-sensitive):
if (myTasks.some(t => t.agent_id === step && t.status === 'done'))
// 'dev' === 'Dev' → false ❌
```

**Result:** No matches found → 0% completion rate → breach alert triggered

### Data Verification

**Active UCs (with non-complete status):** 34 total
- Example workflows: `["product","dev","qc"]` or `["product","Dev","QC"]`
- 6+ UCs in active status (in_progress, ready)

**Sample Tasks:**
```
UC: uc-distribution-loop-fix    | agent: dev   | status: cancelled
UC: uc-distribution-loop-dedup  | agent: dev   | status: cancelled
UC: feat-genome-project-structure | agent: product | status: done
```

The workflows and agent_ids exist, but case mismatch prevents matching.

## Implementation

### Code Fix

**File:** `/Users/clawdbot/.openclaw/genome/core/heartbeat-executor.js` (line 7513)

**Before:**
```javascript
for (const step of workflow) {
  totalSteps++
  if (myTasks.some(t => t.agent_id === step && t.status === 'done')) {
    completedSteps++
  }
}
```

**After:**
```javascript
for (const step of workflow) {
  totalSteps++
  if (myTasks.some(t => t.agent_id?.toLowerCase?.() === step?.toLowerCase?.() && t.status === 'done')) {
    completedSteps++
  }
}
```

**Changes:**
- Normalize both `agent_id` and workflow `step` to lowercase for comparison
- Use safe optional chaining (`?.toLowerCase?.()`) to handle null/undefined gracefully
- Comparison is now case-insensitive
