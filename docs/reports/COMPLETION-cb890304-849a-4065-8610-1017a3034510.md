## Critical Failures

### CF-1: Simulator step never wired into page.tsx
`page.tsx` still uses a 4-step inline flow: `account → profile → integrations → confirm`. The `StepId` type, `STEPS` array, `OnboardingSimulator` import, renderer block, and `ahaCompleted`/`ahaResponseTimeMs` fields in `AgentFormData` were never added.

**User impact:** Zero. No user sees the simulator. AC-1 through AC-9 all fail.

**Fix required:**
```typescript
// 1. Extend StepId
type StepId = 'account' | 'profile' | 'integrations' | 'simulator' | 'confirm'

// 2. Add to STEPS array
const STEPS = [
  { id: 'account', label: 'Account' },
  { id: 'profile', label: 'Profile' },
  { id: 'integrations', label: 'Integrations' },
  { id: 'simulator', label: 'Simulator' },
  { id: 'confirm', label: 'Confirm' },
]

// 3. Import
import OnboardingSimulator from './steps/simulator'

// 4. Add to AgentFormData
ahaCompleted: false,
ahaResponseTimeMs: null as number | null,

// 5. Add renderer
{currentStep.id === 'simulator' && (
  <OnboardingSimulator
    onNext={goNext}
    onBack={goBack}
    agentData={data}
    setAgentData={(updates) => setData(prev => ({ ...prev, ...updates }))}
  />
)}
```

### CF-2: steps/confirmation.tsx is dead code
`page.tsx` has its own inline `StepConfirm`. The `steps/confirmation.tsx` with the Aha row is never imported. The Aha status (✓ Saw AI respond / ⊘ Skipped) is never shown.

**Decision needed:** Use `steps/confirmation.tsx` as final step (recommended — richer, includes pilot plan info + what's next), OR add the Aha row to the inline `StepConfirm`.
