## Problem

The acceptance check `email-columns-exist` was failing because the script `scripts/check-trial-email-columns.js` was outputting extra text from the dotenv banner before the actual count:

```
❌ email-columns-exist: expected "6", got "[dotenv@17.3.1] injecting env (0) from .env -- tip: 🛡️ auth for agents: https://vestauth.com
6"
```

## Root Cause

The script was being invoked via the `dotenv` CLI wrapper which injects a banner message before the script's output. The acceptance check expects ONLY the count ("6") as output.

## Solution

Modified `scripts/check-trial-email-columns.js` to:
1. Explicitly load dotenv with `require('dotenv').config({ path: '.env.local', quiet: true })`
2. Use the `quiet: true` option to suppress the dotenv banner
3. Load from `.env.local` (the project's env file) instead of `.env`
