## Root Cause Analysis

**Problem:** The signup page was reading from sessionStorage key `"lf_utm"` while the UTM capture components were writing to `"leadflow_utm"`. This caused UTM attribution data to be silently lost for paid signups.

**Fix:** Changed `sessionStorage.getItem('lf_utm')` to `sessionStorage.getItem('leadflow_utm')` in `app/signup/page.tsx` line 193.

**Impact:** UTM parameters now correctly flow from landing page → sessionStorage → signup API → database for attribution tracking.
