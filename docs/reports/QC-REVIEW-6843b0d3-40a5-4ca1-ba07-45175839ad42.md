## Issues Found

**Minor (non-blocking):**

1. **Weak price ID guard in nudge route** — `nudge/route.ts` guards Stripe calls with `!PRO_PRICE_ID.startsWith('price_professional')` (line 72). This is inconsistent with `create-checkout/route.ts` which uses the correct `isValidPriceId()` regex. If the env var is set to a value starting with `price_professional`, Stripe checkout won't be created and the fallback `/pricing` URL is used. This is non-blocking (graceful fallback exists) but the pattern is inconsistent. Should use `isValidPriceId()` from the create-checkout route.

2. **DB client naming inconsistency** — Nudge routes use `supabaseAdmin` from `@/lib/db` while `trial/start/route.ts` uses `supabaseServer` from `@/lib/supabase-server`. These resolve to the same underlying PostgREST client, so there is no runtime impact. Cosmetic inconsistency.

3. **No migration in this PR** — The `trial_banner_dismissed` column is used without a migration in this PR. Column exists in the DB (confirmed via psql), added by prior migration. No action needed but worth tracking.

**Not Present (out of scope for this implementation):**
- Trial-expiry email reminders (Day 6/3/1/0 emails) — these are in `lib/trial-emails.ts`, separate from this conversion path
- `/dashboard/upgrade` pricing page with plan cards — PRD spec'd this but `/upgrade` redirects to `/pricing` which serves the same purpose
