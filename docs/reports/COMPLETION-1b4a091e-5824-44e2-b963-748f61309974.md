# Completion Report: Genome replenishQueue ready-status startStep bug fix

**Status:** ✅ COMPLETE

## Summary

Fixed the infinite PM task recreation loop in the Genome orchestrator's `replenishQueue` function. The bug caused UCs with `implementation_status='ready'` to always start at workflow step 0, even when prior steps had already completed.

## Root Cause

In `~/projects/genome/core/heartbeat-executor.js`, the `startStep` calculation logic was guarded by a status filter that only included `['stuck', 'in_progress', 'not_started']`. When a UC was marked as `'ready'`, the calculation was skipped and `startStep` defaulted to 0, causing the orchestrator to create another PM task instead of continuing with the next workflow step.

## Fix Applied

**File:** `~/projects/genome/core/heartbeat-executor.js` (line 7515)

**Before:**
```javascript
if (['stuck', 'in_progress', 'not_started'].includes(uc.implementation_status)) {
```

**After:**
```javascript
if (['stuck', 'in_progress', 'not_started', 'ready'].includes(uc.implementation_status)) {
```
