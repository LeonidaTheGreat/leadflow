## Root Cause Analysis

The deployment drift occurred because:
1. The dashboard middleware was using `jsonwebtoken` which only works in Node.js runtime
2. Next.js middleware runs in Edge Runtime (Vercel's edge infrastructure) which doesn't support Node.js-only packages
3. This caused `FUNCTION_INVOCATION_FAILED` 500 errors on all pages including /login
4. The fix was available in commit `04ba5ec` but hadn't been merged to main
