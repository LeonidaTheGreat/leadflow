## Summary

Fixed the signup page smoke test that was failing due to incorrect test expectations around form validation behavior.

## Problem

The browser test `signup form validation works` was failing because:
1. The test expected a JavaScript validation error message ("required") when submitting an empty form
2. However, the signup form uses HTML5 validation attributes (`required`, `minlength`, `type="email"`)
3. Browser-native HTML5 validation triggers first and prevents form submission before JavaScript validation can run

## Solution

Updated the test in `tests/browser/pages.spec.js` to:
1. Verify HTML5 validation attributes are present on form inputs (`required`, `minlength`)
2. Test that the form prevents submission with invalid data (HTML5 validation working)
3. Verify the form remains visible after failed submission attempt

This approach correctly tests the validation behavior without relying on implementation details (whether it's HTML5 or JS validation).
